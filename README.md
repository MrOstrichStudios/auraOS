# auraOS™
**auraOS™** is a _web-based OS_ built for people with AURA!  
made by **MrOstrich Studios (me)** for **Stardance HackClub 2026**!

## features or whatever:
it has **5 apps**  
-> **Note**s - to write down what u want to remember  
-> **Calendar** - as da name suggests its a calendar (my birthday is pinned!)  
-> **Terminal** - its a hack styled cool terminal with commands  
  -whoami = who r u -_-?  
  -about = tells ya about the os plus credits for assets  
  -clear = clears the terminal (no bs)  
  -help = u ask for help duh  
  -aura = its a secret my guy  
-> **Aura Meter** - custom app to showcase ya aura to other chads out there
