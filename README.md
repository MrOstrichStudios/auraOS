# auraOS™

auraOS™ is a sleek, web‑based operating system designed for aura‑farmers and creators. Built with simplicity and elegance in mind, it delivers a smooth desktop‑like experience right in your browser.

Made by me! for Stardance Hackclub 2026
---

## ✨ Features

- **Notes**  
  A lightweight app for jotting down ideas, reminders, and to‑dos. Notes are saved instantly and styled with auraOS’s frosted UI.

- **Aura Meter**  
  A unique app that tracks your aura energy and provides a visual meter, blending utility with auraOS’s signature design.

- **Calendar**  
  Organize your schedule with a clean, minimal calendar interface. Supports events, reminders, and auraOS’s smooth transitions.

- **Terminal**  
  A built‑in command line for power users. Run commands, explore files, and interact with auraOS at a deeper level.  
  💡 *Easter Egg*: Try typing `aura` in the terminal for a surprise.

- **Files**  
  Manage your documents and assets with a simple file explorer. Drag‑and‑drop support and auraOS styling make file management effortless.

---

## 🎨 Sleek Aura Design

auraOS™ is built around the **Aura Design Language**:
- Frosted glass windows with blur effects  
- Smooth transitions and hover states  
- Minimalist icons and typography  
- A consistent aesthetic across all apps  

This design philosophy ensures auraOS feels modern, fluid, and cohesive.

---

## 🧠 Memory Limitation

auraOS™ does **not** have persistent memory.  
If the page is refreshed or reset, all unsaved data will be forgotten. This keeps auraOS lightweight and simple, but remember to back up important notes or files externally.
